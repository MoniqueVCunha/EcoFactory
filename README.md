# EcoFactory - Sistema de Gestão Industrial Sustentável

O **EcoFactory** é uma plataforma web para monitoramento em tempo real do chão de fábrica, com foco em eficiência operacional, acompanhamento de produção, segurança do trabalho e indicadores ambientais.
